# 스마트 교통약자 안전 인텔리전스 대시보드 (SWE)

React 19와 Vite 기반의 교통약자(어린이·노인) 안전 정보 웹 애플리케이션입니다. 공공데이터포털(`apis.data.go.kr`, `api.data.go.kr`)과 도로교통공단 실시간 OpenAPI를 활용하여 천안시 신부동 및 두정동 일대의 사고다발지역, 어린이·노인보호구역, 주변 안전시설물 현황을 한눈에 시각화하고 취약도를 진단합니다.

## 기술 스택

- **프론트엔드**: React 19, Leaflet (OpenStreetMap)
- **스타일링**: Vanilla CSS (다크 테마 디자인 시스템, Glassmorphism)
- **빌드 및 환경**: Vite 8, ESLint
- **배포 환경**: Vercel (API 리라이트 및 서버리스 프록시)

## 주요 기능

- **취약계층 2대 사고다발지역 실시간 분석**:
  - **보행 노인 사고**: 고령 보행자 교통사고 다발지역 (`frequentzoneOldman`)
  - **어린이 사고**: 어린이 보호구역 내 사고 (`schoolzoneChild`) 및 보행 어린이 사고 (`frequentzoneChild`)
- **다개년 통계 연도 선택 (2012년 ~ 2025년)**:
  - 2012년부터 2025년까지 개별 연도 선택 조회
  - 최근 3개년(2022~2024년) 및 2012~2025년 전체 통합 조회 지원
- **사고다발 구역 목록 및 인덱싱**:
  - 구역별 고유 인덱스 번호 (`No. 1`, `No. 2`...) 표기
  - 노인 사고 / 어린이 사고 직관적 분류 뱃지 및 세부 유형(스쿨존, 보행 어린이, 보행 노인) 구분
  - 공표 기준 연도 뱃지 및 발생 건수, 사상자(사망·중상) 통계 표기
- **인터랙티브 다크 지도 (Leaflet)**:
  - 다크 테마 커스텀 타일 및 사고다발지점 반경 서클(100m~300m)
  - 어린이보호구역(스쿨존, 214개소) 및 노인보호구역(실버존, 88개소) 전국 표준데이터 공간 시각화
  - 신부동(동남구 131) 및 두정동(서북구 133) 원클릭 권역 전환 (부드러운 FlyTo 이동)
- **주변 안전시설 취약도 진단**:
  - 사고다발지점 반경 내 천안시 단속·방범 CCTV, 과속방지턱, 교통신호기(보행등·잔여시간표시기) 실측 데이터 매칭
  - 5대 안전시설 구비 여부 기반 인프라 결측 진단 점수 산출
- **정밀 지점 상세 모달**:
  - 지점명 기반 도로 기하구조(교차로, 오거리 등) 및 위험 요인 분석
  - 사상자 심각도 등급 및 맞춤형 교통안전 행동 수칙 제시
- **완전 반응형 레이아웃**:
  - 데스크톱(2열 분할), 태블릿, 모바일(수직 스택), 초소형 모바일 화면 전 구간 최적화

## 반응형 레이아웃 기준

- **데스크톱 (1025px 이상)**: 좌우 2분할 뷰(인터랙티브 지도 + 상세 패널), 상단 제어 바 및 통계 지표 전체 표시
- **태블릿 (769px ~ 1024px)**: 컴팩트 2열 레이아웃, 가로 스크롤 탭 메뉴, 반응형 상태 인디케이터
- **모바일 (481px ~ 768px)**: 상하 스택 구조(380px 높이 지도 + 하단 스크롤 상세 패널), 2x2 통계 배지, 지도 뷰 최적화
- **초소형 모바일 (480px 이하)**: 320px 지도 높이, 터치 친화적 여백, 폰트 및 패딩 자동 조절

## 시작하기

```bash
npm install
cp .env.example .env   # 발급받은 인증키를 입력하세요
npm run dev
```

## 환경 변수 설정

| 변수명 | 설명 |
| --- | --- |
| `VITE_DATA_GO_KR_API_KEY` | 공공데이터포털(apis.data.go.kr) 일반 인증키 (인코딩/디코딩) |
| `VITE_KOROAD_AUTH_KEY` | 도로교통공단 구형 포털 인증키 (보조용) |

`.env` 파일은 보안상 절대 깃 저장소에 커밋하지 마세요.

## 주요 실행 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 로컬 개발 서버 실행 (Vite) |
| `npm run build` | 프로덕션 번들 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과물 로컬 미리보기 |
| `npm run lint` | ESLint 코드 스타일 및 문법 검사 |

## API 프록시 설정 안내

브라우저 CORS 제약을 방지하기 위해 `/api` 경로를 프록시로 우회합니다.

| 프록시 경로 | 대상 원격 서버 | 용도 |
| --- | --- | --- |
| `/api/koroad_portal/*` | `https://apis.data.go.kr` | B552061 다발지역 다개년 통계 (2012~2025) |
| `/api/datagokr/*` | `https://api.data.go.kr` | 전국 어린이·노인보호구역 표준데이터 |
| `/api/koroad/*` | `https://opendata.koroad.or.kr` | 구형 도로교통공단 포털 연동 |

- **로컬 개발 환경**: `vite.config.js`의 `server.proxy` 설정 활용
- **프로덕션 배포 환경**: `vercel.json`의 `rewrites` 설정 활용

## Vercel 배포 시 유의사항

GitHub 저장소를 Vercel 프로젝트에 직접 연동하여 배포해야 `vercel.json`의 리라이트 규칙이 정상 적용되어 실시간 API가 CORS 및 404 오류 없이 작동합니다.
