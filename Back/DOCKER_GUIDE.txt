================================================================================
천안시 스마트 교통약자 안전 인텔리전스 - 도커(Docker) 배포 및 설정 가이드
================================================================================

[1] 시스템 구성 개요
- 서비스 1: backend (FastAPI 3.12 백엔드 REST API, 포트 8000)
- 서비스 2: ollama (Ollama 공식 추론 엔진, NVIDIA GPU 가속, 포트 11434)
- 연동 대상: React 프론트엔드 대시보드 (http://localhost:5173)

--------------------------------------------------------------------------------
[2] 사전 준비 사항 (모델 파일 배치)
--------------------------------------------------------------------------------
구글 드라이브(또는 코랩)에서 다운로드받은 4비트 양자화 모델 파일을 아래 경로에 넣어둡니다:

  경로: c:\Work\SWE\Back\AI\Qwen2.5-7B-Instruct.Q4_K_M.gguf

* Modelfile은 이미 Back/AI/Modelfile에 해당 파일명을 참조하도록 세팅되어 있습니다.

--------------------------------------------------------------------------------
[3] 도커 데스크톱(Docker Desktop) 환경 설정
--------------------------------------------------------------------------------
1. Docker Desktop 실행
2. 우측 상단 톱니바퀴(Settings) 클릭
3. [General] 탭:
   - "Use the WSL 2 based engine" 체크 확인
4. [Resources] -> [WSL Integration] 탭:
   - "Enable integration with my default WSL distro" 체크 확인
* 윈도우용 최신 엔비디아 그래픽 드라이버가 설치되어 있으면 GPU가 자동 인식됩니다.

--------------------------------------------------------------------------------
[4] 도커 컨테이너 빌드 및 실행 (최초 실행 및 코드 변경 시)
--------------------------------------------------------------------------------
VS Code 터미널 또는 PowerShell을 열고 프로젝트 루트로 이동하여 실행합니다:

  cd c:\Work\SWE
  docker compose up -d --build

- 백엔드 컨테이너 빌드와 올라마 컨테이너 실행이 백그라운드에서 동시에 진행됩니다.
- 상태 확인: docker compose ps

--------------------------------------------------------------------------------
[5] 올라마(Ollama) 모델 등록 (컨테이너 최초 기동 후 딱 1회만 실행)
--------------------------------------------------------------------------------
컨테이너가 켜진 상태에서 아래 명령어를 터미널에 입력합니다:

  docker exec -w /root/ai_models -it cheonan_safety_ollama ollama create cheonan-safety -f Modelfile

- Back/AI 폴더에 있는 GGUF 모델과 Modelfile을 읽어 'cheonan-safety' 모델을 생성합니다.
- 약 5~10초 내로 완료되며, 도커 영구 볼륨(ollama_data)에 저장되므로 재부팅 후에도 유지됩니다.

--------------------------------------------------------------------------------
[6] 정상 동작 검증 (웹 브라우저)
--------------------------------------------------------------------------------
1. 백엔드 및 올라마 연결 상태 점검:
   브라우저 주소: http://localhost:8000/api/health

   * 성공 응답 예시:
     {
       "status": "healthy",
       "ollama_connected": true,
       "available_models": ["cheonan-safety:latest"],
       "active_target_model": "cheonan-safety"
     }

2. AI 진단 API 테스트:
   브라우저 주소: http://localhost:8000/docs (스웨거 인터랙티브 API 문서)
   POST /api/diagnose 에 지점 정보를 보내면 즉시 JSON 진단 결과를 반환합니다.

3. 리액트 대시보드 연동:
   http://localhost:5173 에 접속하여 지도 위의 다발 지점을 클릭하면
   실시간 AI 위험도 판정, 맞춤 행동 수칙, 인프라 개선안이 즉시 출력됩니다.

--------------------------------------------------------------------------------
[7] 자주 사용하는 도커 관리 명령어 모음
--------------------------------------------------------------------------------
- 전체 컨테이너 상태 확인:
  docker compose ps

- 백엔드 실시간 로그 확인:
  docker compose logs -f backend

- 올라마 실시간 로그 확인:
  docker compose logs -f ollama

- 컨테이너 일시 정지:
  docker compose stop

- 컨테이너 재개:
  docker compose start

- 전체 컨테이너 종료 및 삭제:
  docker compose down
