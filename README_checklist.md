# 체크리스트 평가 기준·검증 (3번 파트)

담당: 김재현

보호구역의 안전 점수를 매기는 **체크리스트 기준(설정 파일)**과, 평가 엔진(`SafetyEvaluator`, 2번 파트)이 기준대로 동작하는지 확인하는 **테스트**입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `checklist_criteria.json` | 체크리스트 항목, 배점, 평가 반경, 등급 기준, 감점 규칙 |
| `test_cases.json` | 테스트 케이스 14개 (입력 구역·시설 + 정답 결과) |
| `run_tests.ts` | 평가 엔진에 테스트 케이스를 넣고 정답과 비교해 채점하는 스크립트 |

## 체크리스트 기준

근거는 「어린이ㆍ노인 및 장애인 보호구역의 지정 및 관리에 관한 규칙」(이하 규칙)입니다.

**평가 범위**: 보호구역 좌표 기준 반경 300m (규칙 제3조 제6항: 주 출입문 기준 반경 300m 이내를 보호구역으로 지정)

**점수 항목** (각 20점, 총 100점)

| 항목 | 충족 기준 | 근거 |
| --- | --- | --- |
| 신호기 | 반경 안 신호등 1개 이상 | 규칙 제6조 제1항 |
| 과속방지시설 | 반경 안 과속방지턱 1개 이상 | 규칙 제7조 제3항 제3호 |
| 제한속도 | 반경 안 제한속도 30km/h 이하 | 규칙 제9조 제1항 제3호 |
| 노상주차장 없음 | 반경 안 노상주차장 0개 | 규칙 제8조 제1항 |
| 무인단속카메라 | 반경 안 1대 이상 | 규칙 제11조의2 (설치 근거는 도로교통법 제12조 제4항) |

**점수 계산**

```
기본 점수 = (충족 항목 배점 합 ÷ 데이터가 있는 항목 배점 합) × 100
```

- 데이터가 없는 항목은 분모·분자에서 모두 빼서 감점하지 않습니다 (`no_data`).
- 데이터가 있는 항목 배점 합이 50 미만이면 `lowConfidence: true`(신뢰도 낮음)로 표시합니다.
- 보호구역이 사고다발지역과 300m 안에 겹치면 −20점, 2개 연도 이상 선정된 지점이면 −30점입니다.
- 최종 점수는 0~100점으로 자릅니다.

**등급**

| 등급 | 점수 |
| --- | --- |
| 안전 (`safe`) | 70점 이상 |
| 주의 (`caution`) | 40~69점 |
| 위험 (`danger`) | 40점 미만 |

- 사고다발지역과 겹치는 구역은 점수와 관계없이 최소 "주의"입니다.
- 경로 등급은 경로 주변 구역 중 **가장 낮은 등급**입니다.

기준을 바꿀 때는 코드가 아니라 `checklist_criteria.json`만 수정하면 됩니다.

## 테스트 실행 방법

```bash
npm install -D tsx
npx tsx run_tests.ts ./SafetyEvaluator.ts
```

마지막 인자에 테스트할 평가 엔진 파일 경로를 넣습니다. 각 케이스의 통과 여부와, 실패하면 어떤 값이 기대와 다른지 출력됩니다.

```
PASS TC01 5개 항목 모두 충족
FAIL TC02 데이터 없는 항목은 분모에서 제외 + 신뢰도 낮음
     - CZ-A.baseScore: 기대 50, 실제 100
...
13/14 통과
```

평가 엔진은 `evaluateRoutes(criteria, zones, facilityData)`를 가진 `SafetyEvaluator` 클래스를 내보내야 합니다. 입력·출력 형식은 "체크리스트 근거 정리" 문서 6장을 따릅니다.

## 테스트 케이스 목록

| ID | 확인하는 것 |
| --- | --- |
| TC01 | 5개 항목 모두 충족 → 100점, 안전 |
| TC02 | 데이터 없는 항목은 분모에서 제외, 신뢰도 낮음 |
| TC03 | 사고다발지역 2개 연도 선정 → −30점 |
| TC04 | 사고다발지역 1회 선정 → −20점, 80점이어도 최소 주의 |
| TC05 | 경계값 70점 + 최소 주의 |
| TC06 | 경계값 40점 → 주의 |
| TC07 | 경계값 30점 → 위험 |
| TC08 | 점수 하한 0점 |
| TC09 | 반경 경계: 290m 포함, 310m 제외 |
| TC10 | 제한속도 50km/h → 미충족 |
| TC11 | 반경 안에 단속카메라 없음 → 제한속도는 데이터 없음 |
| TC12 | 노상주차장 있음 → 미충족 |
| TC13 | 경로 등급 = 가장 낮은 구역 등급 (안전 + 위험 → 위험) |
| TC14 | 경로 등급 (안전 + 주의 → 주의) |

테스트에 쓰인 구역과 시설은 기준을 확인하기 위한 가상 데이터입니다.

## 정해야 할 것

- 문서에 없던 기준 두 가지를 임시로 정했습니다. 보호구역과 사고다발지역이 300m 안이면 "겹친다"고 보고(`hotspot_overlap_m`), 반경 안에 단속카메라가 없으면 제한속도를 "데이터 없음"으로 처리합니다 (TC11).
- 데이터가 전혀 없는 구역의 점수와, 주변 구역이 없는 경로의 등급은 아직 정하지 않았습니다.
- 제한속도·노상주차장·무인단속카메라는 천안 데이터 확보 여부를 확인 중입니다.
- 기존 `Back/data/checklist_config.json`과 이 설정 파일을 어떻게 합칠지 정해야 합니다.
- 규칙 조항 번호와 원문은 국가법령정보센터의 최신 원문으로 재확인이 필요합니다.
